# 新壳与回收壳的成本分摊

显式自定义规则不受下文自动预算重算，入口见 [CUSTOM_MANUFACTURING.md](CUSTOM_MANUFACTURING.md)。

## 目标与范围

以下说明自动推导制造配方时的材料分摊方式。

回收壳与新壳仍是同一个物品，装配流程相同；使用新壳时多支付制造壳体的材料。既有库存不追溯计价。

## 主金属与弹体材料

按原方中明确存在的铜、铁、金顺序选一个主金属，作为壳体与弹体之间分摊的对象，不把不同金属折算成等价价格。

reloading.metalCostMultiplier 只作用于这个主金属，默认 0.5。原方里的其他金属按原用量保留，避免把铁芯、弹丸等弹体材料也减半。每发不足一粒的金属省略；其他金属与特殊配料向上取整。火药继续按原方每发用量换算流体，不变。

## 新壳补足主金属

壳体每发目标成本 = 原方每发主金属量 − 当前再装填配方实际消耗的同种金属量。

省略微量金属后留下的预算由新壳承担，不再跟着消失。制壳不再额外套一次固定的“另一半”折扣。当前再装填配方包括显式数据包覆盖；重建顺序已调整为先建立装配配方，再计算制壳价格。

程序在同种金属的粒、锭、块（分别为 1、9、81 粒）中选择投入物。对于每种投入，壳体产量取 floor(投入金属量 ÷ 每壳目标成本)，上限 64；选择平均每壳成本最接近目标、且不低于目标的方案。同价时选择较小的投入单位。

这避免了原来“一粒换若干壳”在大口径中严重少收材料，也避免向上取整产量使新制整发主金属低于原方预算。产量仍为固定整数，不使用概率出壳，不新增成组弹壳或零件。

默认规则示例：

- 9mm 原方每发 1.8 粒铜，再装填直接铜为零；一锭铜制造五壳，每壳 1.8 粒铜。新壳装配主金属与原方相同，回收壳省去这部分。
- .22 WMR 原方每发 0.9 粒铜，直接铜为零；一锭铜制造十壳，每壳 0.9 粒铜。
- 5.56 原方每发 3 粒铜，再装填 2 粒；一粒铜制造一壳，新制合计 3 粒铜。
- 12g 原方每发 7.5 粒铜和 1 粒铁；再装填 4 粒铜和 1 粒铁，壳体目标为 3.5 粒铜。一个铜块制造 23 壳，整发铜成本约 7.522 粒，接近且略高于原方；回收壳无需支付这部分制壳铜。

## 边界

本规则核算的是原方主金属，不声称能比较所有物品的总价值。微量金属省略仍可能减少不足一粒的其他金属；特殊材料向上取整也可能增加单项成本。

若显式装配已经消耗不低于原方的主金属，制壳不会变成免费，而是保守地使用原方完整主金属预算。显式原料存在不同金属或不同规格的候选、无法确定其实际金属用量时，同样保守计价。

缺少可识别原方金属来源时，仍可使用已有的通用铜壳规则。已知原方成本若高到单个金属块也无法表示，则不使用便宜的通用规则绕过，而是跳过该制壳配方；这属于现有“一件金属投入”的工艺表达上限。

制壳配方跟随实际装配材料，且与自动装配优先选择同一个原方。数据包更改或重新配置材料系数后执行 /reload。旧在制品仍受原有配方指纹保护，可单独合成取回弹壳重新开始；已投入材料不退还。

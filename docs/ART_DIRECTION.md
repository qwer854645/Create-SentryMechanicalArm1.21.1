# 物品贴图规范与 alpha.26 接入记录

本规范依据 Minecraft 1.21.1 与 Create 6.0.10 的实际 16×16 物品资源观察归纳，不是官方规范。完整配图分析保存在本轮工作区交付目录 outputs/create-art-style-v2。

## 已采用资源

- casing_mold：已确认的模具试稿，15 色，普通生成物品模型。
- primer_cup：已确认的铜底火壳，8 色。
- primer：与空壳保持相同 Alpha 外轮廓的成品底火，11 色。
- small_gunpowder：紧凑的粒状形，采用原版火药的 7 色灰阶，不再使用整份火药的堆状图标。

四张资源均为实际 16×16 RGBA，路径在 assets/sentrymechanicalarm/textures/item，模型 layer0 使用本模组自己的对应资源。模具不再借用剪刀的模型或贴图。

少量火药的调色板为 #2D2D2D、#3E3E3E、#494949、#505050、#545454、#727272、#8A8A8A；亮部不使用银白色，以保持原版火药的暗灰材质。

## 继续制作时的规则

1. 先看实际 16×16 样本，并区分平面物品图标与自定义模型贴图。
2. 使用重复的有限色阶，组织有方向的亮带、转角和暗面。原版铜锭与 Create 铜粒共享八色，但复杂构件可以使用更多颜色，不能把八色当成所有物品的硬性上限。
3. 避免将“变化”解释成随机污渍、裂纹或满面斑点，也避免只给外圈加亮边、留下单调的大平面。
4. 高清生成稿不是完成的像素资源。导出时整理到实际 16×16，以最近邻处理尺寸并约束到选定材质调色板；不用抖动散点制造新噪声。
5. 检查实际图标、原尺寸和放大图。尺寸与色数检查不能代替视觉验收。
6. 同一零件不同加工阶段优先保留轮廓和视角，通过内部状态区分。底火壳与底火分别表现凹口和钢灰封口。

## 版本范围

alpha.26 仅接入物品贴图与调整模型资源引用。配方、物品 ID、数据组件、消耗量、口径判定与消息协议 10 保持 alpha.25 的实现。

新图由内置 image_gen 制作，原版和 Create 资源用于形状/配色观察与参考；本轮未把参考图原文件作为新物品贴图打包。完整提示词与导出记录随交付文件保存。

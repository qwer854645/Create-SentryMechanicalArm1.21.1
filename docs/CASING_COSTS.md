# alpha.23：单枚再装填的金属粒与少量火药

> alpha.28 已更新装药分档、特殊配料和旧格式来源读取；现行规则见 [POWDER_BANDS.md](POWDER_BANDS.md)。

> alpha.24 新增底火壳与通用底火生产，预留底火铜和火药后计算剩余原料；现行流程见 [PRIMERS.md](PRIMERS.md)。下文属于 alpha.23 版本说明。

环境：Minecraft 1.21.1 / NeoForge 21.1.228 / Create 6.0.10 / 官方 TaCZ 1.2.0 / Java 21；客户端检查使用 JEI 19.21.0.247。

## 加工流程

维持一枚同口径弹壳到一发原枪包子弹的序列装配：机械手加入金属粒，再加入少量火药，最后冲压。每份原料是一道机械手步骤；例如需要两份少量火药时，机械手连续进行两次装药。没有成组弹壳或流体装药。

新增少量火药 sentrymechanicalarm:small_gunpowder。一份原版火药可在合成栏中拆为 32 份，也可用 Create 磨石加工得到同样数量，支持自动化供料。它在模组主创造栏中展示，弹壳栏仍只展示弹壳。当前使用原版火药图标。

## 通用成本规则

只自动处理现有 TaCZ 配方中可理解的普通铜/铁/金、铁粒/金粒、原版火药和纸；保留原有特殊弹药过滤。没有可靠原方、复杂材料、额外组件、容器返还、异种候选原料或超过 16 次加料的成本不自动猜测，需要显式数据包。

1. 铜锭、铁锭、金锭按 1:9 换算为对应粒；铜粒使用 Create 现有物品。原方已是铁粒或金粒时，不再乘九。
2. 金属用量乘 metalCostMultiplier，默认 0.5；这是游戏平衡规则，不是推断金属中有一半一定属于弹壳。纸不享受金属折扣。
3. 原版火药换算为 32 份少量火药，不打折。
4. 同种材料合并后再除以原方产量，按单发向上取整；避免材料分写多项造成重复取整。
5. 如果最终每一种材料都不比原方单发用量少，自动规则跳过该配方，避免出现全材料都不划算的再装填。已存在的显式数据包成本仍按作者数值使用。

默认例子：

- 9mm：一枚弹壳 + 1 铜粒 + 2 份少量火药 → 一发子弹。
- 5.56×45：一枚弹壳 + 2 铜粒 + 3 份少量火药 → 一发子弹。
- 12g：一枚弹壳 + 4 铜粒 + 11 份少量火药 + 1 铁粒 → 一发子弹。

离散物品仍有取整损耗，不能承诺每种材料都正好省一半。9mm 再装填 50 发实际消耗 50 铜粒（约 5.56 铜锭）和 100 份少量火药（3.125 份原版火药），相比原方 10 铜锭 + 2 火药，金属下降、火药上升。规则只排除所有原料均无收益的情况，不为不同材料强行规定统一货币价格。需要更细经济平衡时可明确覆盖成本。

## 配置与数据包

config/sentrymechanicalarm-server.toml：

```toml
[reloading]
enabled = true
autoFromTaCZ = true
metalCostMultiplier = 0.5
```

金属系数范围 0.01–1.0，只影响自动推导；接近 1 时，许多配方会因没有实际材料收益而被跳过。更改系数后执行 /reload。新增配置沿用现有服务端配置文件。

显式覆盖仍在 data/<命名空间>/sentry_reloading/<弹药路径>.json。materials 中写出的物品和 count 完全按字面使用，不再乘金属系数、不自动把火药换成少量火药。例如原有写 minecraft:gunpowder 的数据包依然消耗整份火药；要使用新材料需改为 sentrymechanicalarm:small_gunpowder。

## 升级

客户端和服务端一起更新到 alpha.23（新增物品需要两端一致）。网络消息格式沿用协议 9。自动成本变化会改变再装填配方指纹，旧成本的在制品会停下；单独放入合成栏可取回弹壳，不返还已投入原料。没有修改 TaCZ 自带的新造子弹配方。

## 验证范围

最终结果：服务端 21 项通过；客户端 JEI/少量火药模型/弹壳显示检查通过，标准枪械模型回归 226 项通过、6 个特殊模型沿用既有回退。

当前五个测试枪包组合中，37 种允许弹壳有 15 种可生成自动再装填；其余需要可靠的显式成本，不能将其理解为所有弹壳都有默认配方。

服务端覆盖原配方折算、9mm/5.56/12g 数值、材料合并、复杂/无收益成本拒绝、超大数量与无效系数、火药合成与磨石配方产量、配置重建和成本 ID；还运行真实置物台/机械手/冲压、两份装药精确扣料、单发产物射击后只回收一壳、数据包重载与取消加工。

客户端检查少量火药模型、JEI 合成与磨石配方检索、9mm 再装填原料、37 种弹壳子类型和既有外观。磨石验证的是配方匹配与结果，不是整座磨石供料工厂的运行验收。

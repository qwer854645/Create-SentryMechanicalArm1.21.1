# alpha.21：静态弹壳回收与再装填

本版完成静态工厂第一批功能：普通实体弹药的弹壳进入原有物流设施，由 Create 序列组装再装填为原枪包子弹。没有为指定枪包编写生产特判。原 38% 图标裁剪、亮度和创造栏过滤保留。

## 使用方法

1. 用溜槽、漏斗等收集掉落弹壳，进入箱子或机械动力库存。
2. 按口径分流时，使用列表过滤器并启用匹配数据/组件。普通不匹配数据的物品过滤只识别共用物品 ID，不能区分 AmmoId。再装填配方本身严格匹配口径，不依靠显示名称。
3. 将对应弹壳送到置物台/传送带加工位置，用机械手按配方依次加入材料，最后冲压。可在配方查看器查看当前服务器实际生成的序列。
4. 一枚弹壳只产出一发对应子弹。例：当前原版 TaCZ 9mm 自动成本为 **1 枚 9mm 弹壳 + 1 铜锭 + 1 火药 → 1 发 9mm 子弹**，机械手装铜锭、火药，再冲压。

再装填中间件为独立物品，使用 Create 原生序列进度，不能当作原来的待加工弹壳走整批子弹制造配方。中间件可单独放入工作台取消加工，返回一枚同口径弹壳，不退还已投入材料。

## 自动成本的边界

自动规则只采用 TaCZ 枪械工作台现有配方，不使用口径名字、枪包名字或旧制造分类的兜底成本。要求弹药允许产出弹壳、原方含火药、材料仅由可理解的普通铜/铁/金及其粒、火药、纸等组成，无额外组件或容器返还。空标签、复杂材料、没有可靠原方、超出 16 个材料步骤等情况均跳过。

每种原材料按原方产量折算到单发，并向上取整；**不自动扣减原方的金属材料**，因为 TaCZ 数据未区分其中的弹壳与弹头。这是保守成本，可能比直接制造新子弹更贵，不能将它当作已完成的经济平衡。需要经济上的回收收益时，应通过下述数据包明确规定材料。

当前五个测试枪包组合：37 种可回收弹壳中，17 种能可靠生成自动再装填配方。魔力、电池、火箭等仍不生成。可回收但用到复杂模组材料的类型，需要数据包明确成本。

## 配置

实例的 `config/sentrymechanicalarm-server.toml`：

```toml
[reloading]
enabled = true
autoFromTaCZ = true
```

- enabled：再装填独立开关。还需弹壳 STARTUP 总开关、原子弹制造总开关及动态配方总开关开启。
- autoFromTaCZ：自动成本推导开关。false 时仍可使用显式数据包成本。

修改后执行 `/reload` 更新配方列表。独立开关关闭会阻止旧中间件继续加工；取消加工取回弹壳仍可用。关闭 STARTUP 总开关时，弹壳和再装填中间件都不注册。

## 数据包成本

文件位置：`data/<弹药命名空间>/sentry_reloading/<弹药路径>.json`。

例如 `data/tacz/sentry_reloading/9mm.json`：

```json
{
  "materials": [
    {"ingredient": {"item": "minecraft:gunpowder"}, "count": 1}
  ]
}
```

此示例会改成一枚对应弹壳加一份火药，产出一发对应子弹，是手动平衡示例，不会由模组自动启用。材料使用原生 Ingredient 格式，也可用 tag；count 默认 1，必须为正整数，总计 1–16 个材料步骤。原料列表不能为空，也不能用空气或匹配空手的原料冒充成本。错误配置会记录警告并跳过该弹药，不偷偷回退自动成本。

禁用某口径再装填：

```json
{"enabled": false}
```

输出数量始终为 1。优先保留对应 TaCZ 原配方产物的组件；没有原方时，用当前 AmmoId 构造标准 TaCZ 子弹。资料里可用空弹壳的类型仍由服务端弹壳规则决定，单独提供成本不会绕过禁止抛壳的规则。

配方 ID 带有材料/产物指纹。成本改变后旧中间件会停下，不会把已完成的便宜步骤直接套用到新配方；可取消加工回收弹壳，重新开始。相同成本重新载入时 ID 保持稳定。服务器同步客户端配方和原料类型；网络协议升至 **8**，多人游戏需两端同时更新。

## 已完成的验证

- 真实 Create 溜槽 → 原版漏斗 → 箱子，收集 17 枚 9mm 与 11 枚 12g 弹壳。
- 从实际收集库存取出一枚 9mm 弹壳，送入真实置物台与机械手；各消耗一次材料，真实冲压机输出一发原枪包子弹。
- 将这一发工厂产物计入枪内的一发弹药，调用原生 TaCZ 射击，消耗该发并只返回一枚弹壳。
- 17 种生成配方的 Create 原生步骤选取、结果和一对一数量；错误口径拒绝、额外名称不改变口径、原料/配方 JSON 与网络编码。
- 传送带运输记录的复制和保存恢复保留 AmmoId、数量和位置；按组件匹配的 Create 过滤器区分口径。
- 中间件 ItemStack 存盘/恢复后继续加工，成本数据包实际重载、禁用、空成本/空气成本拒绝、移除后恢复、配方重建不重复。
- 客户端中间件名称、口径、四种显示上下文及配方同步；原射击与弹壳回归，STARTUP 总开关关闭验证。

机械手转速和补料由测试夹具控制；不是一座完全由漏斗供料、传送带串联的整厂无人值守验收。箱体/置物台/机械手/冲压是实际方块运行，传送带本次验证了运输数据格式，未单独验收整段带速/分流线路。动态结构、列车、Sable 工厂和 createimmersivetacz 桥接尚未扩展。

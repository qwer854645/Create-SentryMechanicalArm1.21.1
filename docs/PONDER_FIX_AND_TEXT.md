# alpha.40：修复空白思索、面板模型与文案

> 本文保留 alpha.40 的历史记录。alpha.41 已继续修复方块实体、旧物品数据、染色与枪焰渲染，并完成九段思索的客户端验证；现行结论见 [发布前检查](RELEASE_READINESS.md)。

## 空白思索

alpha.39 的新结构只有 y=0 地板，依赖脚本在 y=1–3 临时放机器。Ponder 1.0.82 的 `ReplaceBlocksInstruction.runModification` 在修改前检查 `PonderLevel.getBounds().isInside(pos)`，边界外直接返回；初始地板没建立机器高度范围，后续放置指令被忽略。

本版改为五份预置实际机器的独立结构：`casing_forming.nbt`、`casing_reloading.nbt`、`casing_collection.nbt`、`sentry_depot_supply.nbt`、`sentry_targeting.nbt`。场景注册分别引用它们，机器在载入时已经存在，删除了新教程的临时 setBlock 建造指令。原四份 NBT 和原场景主体保留。

生成器为机械手明确设置向下朝向；装填章节补上固体加料所指向的机械手工位。压机演示设置转速，模型和文字均指向当前展示的设备。场景仍是受控教学演示，不是完整生产线验收。

## 收集器模型

按用户澄清，保持完整安山机壳主体，只将顶部做成漏斗背面那块面板。移除 alpha.39 的整套漏斗进料口、斜板及其他板件。

顶部使用居中的薄面板（12×12、厚 1 像素），上表面引用水平安山漏斗贴容器背面的 UV 区域，面板边缘引用对应边框纹理。底部及侧面保持安山机壳。只引用 Create 材质，不复制 PNG。选框和碰撞更新为完整机壳加顶部薄面板。

## 文案

直接阅读 Create 6.0.10 的中英文原始思索和工具提示，整理为 [CREATE_TEXT_STYLE.md](CREATE_TEXT_STYLE.md)。

重写最近新增的五段思索及上一轮改动的旧文本，中英文与源码默认文本一致。改为短句描述当前动作，删除教程中的开发历史、内部术语和成本算法；材料与数量明细保留在配方显示和文档中。

模具和收集器接入 Create 原生详细提示，按“用途—触发条件—行为”组织，并使用标准重点配色。弹壳继续沿用先前要求的弹药式提示；口径状态和高级 ID 保留。同步精简瞄准镜、许可操作、供弹状态及搜索提示，保留原主题名称和主题短句。

## 执行范围

本版按源码和 Ponder 指令实现定位原因，并执行编译打包。未运行检查、测试、客户端或服务端；不将编译通过表述为已经验收全部场景的镜头和播放。没有修改弹药费用、收集规则或网络协议。

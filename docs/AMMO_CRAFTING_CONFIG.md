# 子弹制作功能开关（alpha.10）

新增服务器配置，默认开启：

```toml
[ammo_crafting]
enableAmmoCrafting = true
```

设为 false 后保存，并重启世界或服务器。此选项使用 NeoForge 的 worldRestart 配置语义，单独执行 /reload 不会使修改后的值立即生效。

配置文件为当前存档的 serverconfig/sentrymechanicalarm-server.toml。单人游戏通常位于 saves/<存档名>/serverconfig/；独立服务器通常位于 world/serverconfig/，若修改了 level-name 则使用对应世界目录。升级后首次打开世界会自动补充新选项。建议客户端和服务端同时更新 alpha.10。

## 控制范围

关闭本模组提供的子弹制造：自动生成的切割、序列装配、独立压制配方；工作台弹药模板；机械手用弹药处理铜板的模板加工；旧传送带铜板/火药加工。保留已有物品，不删除已存储的弹药或半成品；关闭时半成品不能继续由本模组制造流程加工。

不影响 TaCZ 自带的工作台配方，不影响哨戒臂射击、换弹、弹药盒装填、弹药库供弹和动态结构库存。第三方数据包自行定义的独立配方不由此选项全局拦截。

原有 dynamic_recipes.enableDynamicRecipes 仍保留，仅用于控制自动生成配方。新总开关优先：总开关关闭时，即使旧选项开启，也不生成配方。

## 验证

- 真实 TOML 设置为 false，独立服务器启动确认总开关关闭且没有自动制造配方。
- 关闭状态下静态射击、换弹与供弹专项 31 项通过；弹药库专项 42 项通过，包含动态共享库存与真实 Sable 场景。
- 重载与制作专项 25 项通过，新增验证模板匹配/产出、材料不被消耗、缓存的压制配方、进行中的序列装配、关闭后自动配方清除和重新开启恢复。测试切换重启型配置时显式清除测试缓存，实际使用仍需重启。
- 正常发布构建不包含测试类或测试世界；网络协议保持 5。

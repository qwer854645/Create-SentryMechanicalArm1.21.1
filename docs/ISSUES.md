## 游戏内验收顺序

1. 新建测试世界，仅使用固定依赖和默认枪包；静态哨戒臂装枪、供能、敌对索敌、遮挡、射击和补弹。
2. 重复地面/吊顶、不同射程、不同武器类型；比较模型枪口、实际弹道和命中位置。
3. 保存重进、区块重载、拆装回收；逐次记录枪械、配件和弹药总数。
4. 专用服务器连接两名玩家，验证目标、角度、弹药和动画一致。
5. 序列组装实际生产、含组件的材料、同名弹药、/reload。
6. 然后扩展到动态结构、第三方枪包，最后单独加入 Sable。

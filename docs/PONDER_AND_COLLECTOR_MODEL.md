## 收集器模型

此前 alpha.37–38 是整方块顶部引用漏斗背面。按用户要求，本版改为下半部安山机壳、上半部实际漏斗几何。上部取自 Create 6.0.10 的 `block/funnel/block_horizontal`：保留背板、侧板、倾斜进料板等六组元素，统一转向并以 0.75 比例缩放，让原本侧向贴着容器的背面朝上，与机壳基座结合。

模型 JSON 保存变换后的几何，材质直接引用 Create 的安山漏斗、背板、方向板、未激活侧板与安山机壳等资源。没有复制或打包 Create PNG。选择/碰撞采用下部半高机壳与上部漏斗包络，并关闭完整立方体遮挡；碰撞是简化包络，不是逐斜面网格。

可用 `scripts/update-collector-model.py <Create jar>` 重新生成几何。该脚本只读取已安装 Create 的模型 JSON，不是游戏运行依赖。

## 新增五段思索

新增一个独立的 9×9 工坊结构底板，不改旧结构。教程分开编排：

- **用模具制造弹壳**：从模具、弹壳进入。选择口径、机械手持模具、加工金属、模具保留、新壳与回收壳共用。
- **流态装药与单发再装填**：从弹壳、半成品、模具进入。无水无热搅拌、储液、注液、必要固体、冲压、注液容量与旧半成品回收。演示默认 9mm，提示实际费用以 JEI 为准。
- **收集射击后的弹壳**：从动力臂、收集器、弹壳进入。六面相邻、27 格直存、物流抽取、余量落地、同结构移动与玩家背包收集。
- **弹药库自动补给**：从动力臂、三种 TaCZ 弹药库进入。兼容弹药盒、相邻匹配弹药、移动库存和供弹失败提示。
- **名单模式与瞄准镜指挥**：从火控台、许可、哨戒瞄准镜进入。名单语义、自我保护、绑定、实体/坐标标记与爆炸武器限制。

补充思索索引中的瞄准镜、收集器及启用时的模具/弹壳/半成品。启动配置不注册弹壳时，不注册依赖这些物品的新制造章节；补给和火控章节仍可使用。

新增文本均提供中英文。思索是受控教学动画，库存、加工和结构移动由场景脚本演示，不作为自动化生产线或真实移动库存验收证据。

## 执行范围

本版只编译打包，不运行检查、测试、客户端或服务端。没有关闭或重启用户现有客户端。新场景的镜头、遮挡、翻译显示和播放过程尚未在游戏内验收。

注册内容与协议保持不变，客户端和服务端使用同一版本。现有库存、配方和收集逻辑不因模型和教程变化而调整。

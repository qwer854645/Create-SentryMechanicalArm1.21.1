# alpha.41 发布前检查

检查日期：2026-11-08。结论：适合作为 **Alpha 公开测试版**交付，暂不建议标为稳定正式版。本轮不包含向 CurseForge 等平台上传。

## 修复内容

- 新思索结构补齐方块实体 NBT。Ponder 恢复渲染列表后，机械手活动部分、冲压机、流体等才有完整的动态渲染。
- 保留原四段思索布局，迁移其中八份 TaCZ 旧 `Count/tag` 物品数据为 1.21 的 `count/components`，保留原枪械 ID、弹量和模式。另将四份旧空物品表示规范为空栈。
- 修复染色臂 UV：五个臂部模型实际取图自本模组 sentry_base，旧换色表却按 Create mechanical_arm 换算，导致采样到错误的图集区域。统一为实际烘焙来源，对全部 16 色检查源精灵和目标 UV 边界。
- 按 TaCZ 原生逻辑跳过 renew 枪焰的旧式平面绘制，并防御空纹理；不再因空指针中断炮台及其后方场景的绘制。
- 隔离静态炮台渲染的 PoseStack，防止外部枪械效果异常污染调用者矩阵；降低逐帧调试日志等级。
- 发布 JAR 加入原 LICENSE，执行独立内容检查，确保没有把测试类、世界、枪包或 Create 资源目录一并发布；新增收集器继续引用 Create 材质。

## 如何解释测试中的失败与日志

初轮保留的失败日志不作为最终通过证据。它们分别帮助定位了真实渲染问题及旧测试夹具中的过时步骤、材料和地面抛壳预期。测试已更新为现行工艺；默认背包与地面模式分别验证，没有靠删除断言规避失败。

测试枪包中有旧工作台数据、缺失纹理和无模型枪口等外部资源问题，部分会由 TaCZ 输出错误或使用既定回退。测试包不随发行包分发，不把这些信息混同为本模组所有功能失败，也不宣称所有第三方资源已经修复。

**Create JEI Compat 1.0.3 不能放进独立服务端**：实际测试会因加载客户端 Screen 类失败。它仅作为客户端可选辅助，既不是本模组前置，也没有内嵌进本模组 JAR。移除后，含 Sable/航空学的独服专项正常完成。

## 发布范围与剩余限制

可以公开 Alpha，收集真实整合包反馈。稳定正式版仍建议补完两个独立客户端连接独服时的同步、重载、容器交互与长时间运行验收。

本轮 Sable 收集验证使用实际旋转结构，但不代表多船并行、长时间跨区块及所有拆装时序都已穷尽。VS2 只有可选兼容路径，本轮没有安装实测，不列为正式验证支持。

renew 枪焰不使用旧式平面纹理。本版修复了错误绘制与崩溃；炮台专用 renew 粒子外观不在本轮完整验收范围内。此限制不影响实际弹道、弹药结算及弹壳收集。

复杂枪包材料和特殊弹药仍应使用显式数据包表达；自动识别与自动制造不是对任意枪包的无条件保证。

升级时注意：alpha.30 已移除底火、底火壳和小火药，不提供这些旧库存的转换；旧再装填半成品可单独合成取回空壳。关闭启动注册开关会使弹壳物品不再注册，客户端与服务端必须保持一致。

# alpha.14：直接裁剪枪包子弹图标

按用户最新要求，取消重新绘制弹壳轮廓和取色生成像素画的方案。背包/快捷栏默认读取 TaCZ 当前 AmmoId 的 slot 图标，裁去弹体图案顶部约 30%，复制剩余原始像素，不改色、不补画尖头或边框。

裁剪前按透明边界定位图案，对下方突然变宽的口径文字作通用排除；不包含枪包名称、口径 ID 或特殊包分支。第三方自定义排版、斜放、多发组合和文字与弹体重叠时，无法保证精确区分弹头与弹壳；这是一套默认裁剪规则，不是语义识别。仍允许同口径子弹的多发组合图案保留为组合弹壳图案。

掉落/手持：枪包有完整弹壳模型和贴图时继续使用；缺失时使用裁剪图的双面物品外观。子弹图标也缺失时保留原通用兜底。没有重新生成或打包第三方贴图，裁剪图仅在客户端内存中生成。

生成纹理按 AmmoId 缓存，资源重载、退出世界时释放并重新生成。服务端耗弹、弹壳产出规则、配方和网络协议没有改动。

验证包括：合成测试图检查弹头及独立文字被裁掉、剩余壳体像素颜色与数量不变；实际枪包四种显示上下文；真实资源重载后重新生成纹理；客户端模型矩阵和 clean build。截图左侧是背包裁剪图，右侧是世界显示。预览包含人为创建的所有弹药样品，不代表全部弹药都实际产出弹壳。

最终验证：五个测试枪包同时加载，44 个弹壳预览样品；裁剪像素专项通过，实际资源重载通过，客户端模型检查 226 项通过、0 失败、6 个使用原有回退；clean build 成功。
